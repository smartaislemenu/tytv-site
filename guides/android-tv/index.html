Shield & other Android TV

Nvidia Shield and other Android TV boxes

  1. Allow installs from the browser (or Downloader)

    Open Settings → Apps → Special app access → Install unknown apps and allow your browser — or install Downloader from the Play Store and allow that instead. Older Android TV builds may say Security → Unknown sources.

  2. Download the APK

    On the box browser open tytvapp.com and tap Download, or in Downloader enter tytvapp.com/apk.

  3. Install

    Open the APK and tap Install. Confirm any Play Protect prompt.

  4. Open TYTV

    Launch TYTV from your apps and add your M3U playlist URL or file. The app ships empty — you choose the content.

Shield note: Nvidia Shield menus match Android TV closely. If a USB drive is easier, copy TYTV.apk from a computer and install with a file manager that has install permission.
