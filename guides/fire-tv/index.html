Fire TV Stick / Fire TV

Amazon Fire TV Stick and Fire TV cubes/boxes

  1. Install Downloader

    From the Fire TV home screen, open the Amazon Appstore and install the free app named Downloader (by AFTVnews). It’s the usual way to install APK files on Fire TV.

  2. Allow apps from unknown sources

    Open Settings → My Fire TV → Developer options (on some sticks: Settings → Device → Developer options). Turn on Apps from Unknown Sources / Install unknown apps for Downloader. Menu names differ slightly by Fire OS version.

  3. Enter the short download link

    Open Downloader. In the URL box, type tytvapp.com/apk and select Go. That link always points at the latest TYTV APK on this site.

  4. Install TYTV

    When the file finishes downloading, tap Install, then Done / Open.

  5. Find the app and add your playlist

    TYTV appears under Your Apps & Channels (or the apps library). Open it and paste your own M3U playlist.

Fire OS tip: If Developer options is missing, go to Settings → My Fire TV → About and click the device name seven times to unlock it, then go back.
