Install guides / Web browser

Web browser

Watch in Safari, Chrome, Edge, and Firefox

  1. Open the web player

    Go to tytvapp.com/watch on a computer or phone browser.

  2. Unlock (when available)

    The player uses the same email + code unlock as the TV app. Until payments go live you’ll see a clear Coming soon message on the gate. A public demo is available for testing the UI at /watch/?demo=1.

  3. Add your playlist

    After unlock, paste an HTTPS M3U playlist URL (same idea as the TV app). Playlists stay in your browser storage on that device.

  4. Play

    Pick a channel or title. The browser uses HLS when the stream supports it.

Browser limits: Streams served over plain http:// can’t play on this HTTPS site (browser security). Some providers also block browser playback (CORS). When that happens, TYTV shows a plain message and you’ll need the TV app instead. That’s expected — not a broken download.
